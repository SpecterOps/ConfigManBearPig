# Emit HasSession from MSSQLSvc SPN host to service account during low-priv LDAP

@_Mayyhem (fixture review 2026-07-31): 'HasSession should be created from the Computer in the host portion of an MSSQLSvc SPN to the service account during unprivileged LDAP collection.' Currently edge-hassession-cas-db and edge-hassession-ps1-db PASS privileged and FAIL unprivileged (not found). AD holds the needed data at low privilege: sqlsccmsvc carries MSSQLSvc/ps1-db.mayyhem.com:1433, MSSQLSvc/cas-db.mayyhem.com:1433 and MSSQLSvc/ps2-pss:1433, so the host->service-account mapping is readable by any domain user. Both cases should therefore be UNPRIVILEGED, not tagged requires_privilege.

## Acceptance Criteria

A lowpriv collection emits HasSession from the SPN host computer to the SPN-holding service account; edge-hassession-cas-db and edge-hassession-ps1-db pass unprivileged.
