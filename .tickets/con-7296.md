# Emit MSSQL nodes/edges as source_kind=MSSQL payload + zip graph output on --run-all

Moved MSSQL_* nodes and MSSQL-only edges to their own OpenGraph payload tagged source_kind=MSSQL (mssql_nodes-*.json / mssql_edges-*.json) instead of emitting them under the SCCM source. transforms._graph_edges_split is now a three-way partition: AD-touching edges -> graph_edges_ad (untagged), edges with BOTH endpoints MSSQL -> graph_edges_mssql, everything else (incl. MSSQL<->SCCM like SCCM_AssignAllPermissions) -> graph_edges_sccm. main.py adds MSSQL_NODE_SPECS/MSSQL_EDGE_SPECS/MSSQL_SOURCE_KIND and a third _emit_split_graph pass. Added shared-library helper openhound_collector_common.orchestration.zip_graph_output, called from run_end_to_end, so --run-all bundles the graph *.json into graph/configmanbearpig_collection_<ts>.zip (released as openhound-collector-common v0.1.1).
