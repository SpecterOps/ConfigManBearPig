# Guard the remote sitesigncert X.509 parse and log parse failures distinctly

collectors/http.py:127 calls x509.load_der_x509_certificate(bytes.fromhex(hex_der)) with no local try/except. Both calls raise ValueError on hostile input (malformed hex, malformed DER), and the bytes come from the unauthenticated remote endpoint http(s)://<mp>/SMS_MP/.sms_aut?sitesigncert. The only handler is the broad 'except Exception' at http.py:492, which logs at VERBOSE as 'failed or not applicable' -- collapsing endpoint-absent, network-failure and parser-rejected into one indistinguishable message. The sitesigncert probe is the only credential-free way to identify the Site Server, so a silent parse failure loses that identification with no diagnosable trace at default log level. Also the reason cryptography 49.0.0 was rejected: it newly raises ValueError on certs with NULL AlgorithmIdentifier params.

## Acceptance Criteria

A malformed hex payload and a malformed DER payload each produce a distinct WARNING naming the target and the reason, and the probe still returns cleanly without aborting HTTP collection. Regression tests cover both.
