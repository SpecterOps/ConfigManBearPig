# Wire integration harness low-privilege mode to a CLI flag

integration/__init__.py:26 accepts privileged: bool = True and its docstring states False is correct for a graph collected without AdminService/WMI. main.py:1387 calls it without that argument, so it always defaults to True, and no CLI flag exists. The only callers passing privileged= are tests/integration_lowpriv_fixtures_test.py:117,121 -- an implemented, documented, unit-tested mode reachable only from a test. Measured against a real lowpriv lab graph: privileged=True gives 29 pass / 43 fail / 1 skip; privileged=False gives 28 pass / 36 fail / 1 skip, skipping only 5 edge and 3 node cases. So the flag both is unreachable AND under-covers: 36 cases still fail at low privilege. This ticket covers the CLI wiring only; the requires_privilege tagging audit and fixture refresh are separate.

## Acceptance Criteria

A CLI flag selects low-privilege fixture mode, main.py passes it through, --help documents it, README documents it, and a test proves the flag reaches run_integration_tests.
