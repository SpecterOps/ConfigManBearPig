# Quiet expected http_/smb_ fallback-table misses in preproc (WARNING->DEBUG when a privileged transport ran)

The preproc transform 'node_computer<-http_smsproviders' logs a WARNING 'skipped (missing source)' whenever the http_smsproviders table is absent. Root cause (not a bug): the SMS Provider host IS the AdminService host, so it is privileged-collected and the HTTP fallback probe is skipped (per_host_phases.py:116-123, mirrors ps1:8617); the http_smsproviders dlt resource yields 0 rows so dlt never creates the table. Same applies to smb_* when every host is privileged-collected. Fix: extend the SCCM expected_miss predicate (transforms.py _sccm_sibling_miss) so an absent http_*/smb_* fallback role table downgrades WARNING->DEBUG ONLY when a privileged transport ran this collection (any adminservice_*/wmi_* table exists). In HTTP-only/SMB-only runs (no privileged table) the miss stays a WARNING. Add targeted tests in tests/transforms_safe_fallback_test.py and update ARCHITECTURE.md logging/diagnostics section.
